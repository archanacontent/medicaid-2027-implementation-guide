# Six-Month Renewals

## The Renewal Rules

<span class="mcd-label">Automatic renewal first</span>
A state has to attempt renewal with the data already on file. If the data falls short, the member gets a prepopulated form and at least 30 days to send it back.

<span class="mcd-label">Two ways to make the switch</span>
CMS's [State Medicaid Director Letter of March 6, 2026](https://shvs.org/resources/new-cms-guidance-on-six-month-renewals-in-medicaid/) gives states a choice. They can keep each member's current renewal date and start six-month periods at the next renewal. The alternative is to pull renewals forward from January 2027. No period can start before January 1, 2027 or run shorter than six months, and any member whose 12-month period is cut short must be told in writing.

<span class="mcd-label">Mixed households</span>
One household can now hold members on different renewal cycles. If a six-month renewal surfaces information about another member of the household, the state has to handle it as a change in circumstances.

## Where The Two Deadlines Collide

Pulling renewals forward risks a [renewal surge in January 2027](https://ccf.georgetown.edu/2026/03/06/cms-releases-guidance-on-6-month-medicaid-renewals-for-expansion-adults/), the month work checks begin. Caseworkers would take on two new processes in the same weeks, and members would receive a heavier stack of notices. CMS has warned that processing backlogs could expose a state to compliance action. Keeping existing renewal dates is the safer choice, because it spreads the work across the year.
