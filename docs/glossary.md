# Glossary

- **Ex Parte Renewal** - Renewal based on data the state already holds, with nothing asked of the member.
- **Expansion Adults** - Adults eligible for Medicaid through the Affordable Care Act's expansion group.
- **Interim Final Rule** - A rule that takes effect before public comment closes. The agency can revise it afterwards.
- **Look-Back Period** - The months before an application that a state reviews for compliance.
- **Procedural Disenrollment** - Loss of coverage over paperwork, such as a form never returned, with no finding of ineligibility.
