# Glossary

- **Ex Parte Renewal** - renewing a member's coverage using data the state already holds, without asking the member for anything.
- **Expansion Adults** - adults who qualify for Medicaid through the Affordable Care Act's expansion group.
- **Interim Final Rule** - a rule that takes effect before the public comment process finishes, and that may later be revised.
- **Look-Back Period** - the months before an application that a state checks for compliance.
- **Procedural Disenrollment** - losing coverage for a paperwork reason, such as an unreturned form, rather than for being found ineligible.
